## ⚙️ System Requirements

To run this application, ensure your computer meets these minimum specifications:

* Memory: 4 gigabytes of RAM or more.
* Storage: 500 megabytes of free space.
* Internet Connection: Stable connection for AI responses.

The software runs locally on your machine but requires an active internet connection to communicate with the Anthropic servers.

## 🔑 Initial Configuration

The application requires an Anthropic API key to function. This key acts as your personal authorization to use the service.

1. Launch the Claude-Mythos application from your start menu or desktop icon.
2. Locate the settings menu found in the bottom left corner.
3. Select the API key field.
4. Log into your Anthropic developer account in your web browser to generate an API key.
5. Copy the generated key and paste it into the application field.
6. Click Save to store the key securely in your local configuration.

## 📝 Using Character Cards

Character cards transform how the AI behaves during your sessions. This feature gives the AI specific personality traits, backstories, and speaking styles.

* Create a new card: Select the plus icon in the character library tab.
* Name the character: Input a title to identify your new persona.
* Define the prompt: Write instructions that describe how the AI should talk and think.
* Save the card: Your new character appears in the sidebar for easy access.

When you start a new conversation, select a character card to apply those rules to the chat. The AI will adopt the persona immediately.

## 🧠 Managing Deep Reasoning

The application supports deep reasoning and chain-of-thought methods. These tools improve the quality of long-form writing or complex problem-solving.

* Enable reasoning: Toggle the switch in the chat window header.
* Select model: Choose the model version that supports deep reasoning from the dropdown menu.
* Monitor thoughts: Expand the thought panel to see the steps the AI takes to reach a conclusion.

This process helps the AI plan its response before it writes the final text. Use this mode for creative writing tasks where detail and logic matter.

## 💾 Organizing Chat History

All conversations save to your hard drive automatically. You can export or import these sessions if you move to a different computer.

* Folders: Use folders in the sidebar to group conversations by topic or character.
* Search: Use the search bar at the top of the chat list to find past interactions.
* Rename: Right-click any chat title to name it for better organization.

## 🛠️ Troubleshooting Issues

If the application does not work as expected, check these common fixes.

* Blank Screen: Close the application and restart it. This resets the interface.
* Error Messages: Check your internet connection status.
* API Key Errors: Return to your Anthropic dashboard and confirm that your account has remaining credits. The AI cannot function without an active balance.
* Update Software: Periodically check the release page to see if a newer version exists. Newer versions often fix display bugs and improve stability.

## 🔒 Data Privacy

The application stores your chat history and configuration files on your own hardware. Your API key remains stored in your local settings folder. The developer does not have access to your keys or chat logs. Ensure you keep your computer secure to protect your local data.
