## Overview
**Claude Mythos AI App** is a beautiful and powerful desktop client for Claude AI by Anthropic. Designed with the stunning Mythos aesthetic, it offers an immersive experience for creative writing, roleplay, deep reasoning, coding, and long-context conversations.

> [!Important]
> This application requires an official **Anthropic API Key**. Everything runs locally and privately on your device.

## Key Features
- **Mythos Aesthetic Design**: Elegant and modern dark interface
- **Excellent Roleplay & Creative Writing** support
- **Advanced Reasoning** with full Chain-of-Thought
- **Ultra-Fast Streaming** responses
- **Multi-Modal** support (images, documents, vision)
- **Privacy First**: Local chat history and encryption
- **Custom System Prompts** and advanced prompt tools
- **Lightweight & Highly Optimized**

## Installation
### For Regular Users
1. Download the latest release
2. Extract the archive
3. Run `ClaudeMythos.exe`
4. Paste your Anthropic API Key
5. Start chatting with Claude
